Authentication

Stable token mode keeps the same token across restarts, stored in your Thunderbird profile while the add-on is enabled. If the token becomes known to someone else it stays valid until you regenerate or clear it. Changes apply next time the MCP server starts.

Send Safety

This setting is enabled by default. While enabled, MCP clients requesting skipReview: true on sendMail, replyToMessage, forwardMessage, createEvent, or createTask are rejected; the review window or dialog remains available. skipReview is honored only after you explicitly disable this setting.

Filter rules that send mail (forward / reply)

A filter rule that forwards or replies sends mail automatically, every time, with no review window. An MCP client (an AI assistant) could be tricked by a message it reads into asking for one. This setting decides what happens when an MCP client asks to create or change such a rule, or to change or run a filter list that already holds one.

Whatever the setting: rules that send mail on outgoing mail are refused, and MCP clients can never accept a confirmation themselves. Every request and answer is recorded in commonpost-mcp-confirmations.log in your profile folder (no message content).

Encrypted messages

OpenPGP and S/MIME messages are kept private by default: the assistant is told that a message is encrypted and receives no content, and replyToMessage / forwardMessage do not send such a message without review. If you enable the option below, Thunderbird decrypts these messages for the tools and their decrypted content is handed to the assistant, and so to the service that runs it.
