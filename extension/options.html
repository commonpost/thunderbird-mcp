    Send Safety

    What the assistant may do on its own, and what waits for you.

    Technical details

    While the first setting is on, MCP clients asking for a direct send are rejected: skipReview: true on sendMail, replyToMessage or forwardMessage, and mode: "send" on replyToMessage or forwardMessage; the review window remains available. mode: "draft" only saves a draft, sends nothing and is not blocked (it needs the saveDraft tool under Tool Access).

    While the second setting is on, createEvent and createTask open Thunderbird's dialog and skipReview: true is rejected; while it is off, a client can still ask for the dialog with skipReview: false. An installation updated from a version without this setting takes the value of the first one.

    Filter rules that send mail (forward / reply)

    A filter rule that forwards or replies sends mail by itself, every time, without review. A message the assistant reads could trick it into asking for one.

    Technical details

    Whatever the setting: rules that send mail on outgoing mail are refused, and MCP clients can never accept a confirmation themselves. One request at a time, at most 5 per hour. Every request and answer is recorded in commonpost-mcp-confirmations.log in your profile folder (no message content).

    Encrypted messages

    OpenPGP and S/MIME messages stay private by default: the assistant only learns that a message is encrypted, and replyToMessage / forwardMessage do not send one without review.

    Advanced

    Leave these as they are unless you know you need them.

    Network

    Every device on your network can then reach the server, over plain HTTP: the access token travels in clear text and anyone there can read it, and the check of the Host header is off in this mode. Turn it on only on a network you fully trust, and off again when you no longer need it.

    Authentication

    Before you use a stable token

    The token is stored in your Thunderbird profile. If it becomes known to someone else it stays valid until you regenerate it or uncheck "Use stable token". Removing the add-on while it is enabled clears the stored token; if you disable the add-on first, uncheck "Use stable token" before removing it, since removing an already-disabled add-on leaves the token in the profile.
